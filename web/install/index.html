Installation directe

pas de certificat valide

Installer sans aucun outil, en un geste depuis Safari — dès qu'un certificat de signature valide sera en place.

À savoir — signé avec un compte Apple gratuit, l'app se réinstalle toute seule tous les 7 jours via ton signeur. Un IPA installé avec un certificat révoqué refuse de s'ouvrir : reviens ici et prends une autre voie.
